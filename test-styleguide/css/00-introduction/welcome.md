This styleguide is generated by [kss-modern](https://github.com/felixranesberger/kss-modern)
from plain CSS files with KSS comment blocks. Every page shows one feature of the
generator. The source lives in
[`test-styleguide/`](https://github.com/felixranesberger/kss-modern/tree/main/test-styleguide).

:::alert{type="info" title="Try the UI"}
Press `Cmd/Ctrl + K` to search, use the arrow keys to move between pages and switch
between System, Light and Dark in the header. The **Theme** dropdown in the header
restyles every preview.
:::

:::accordion{title="How this demo is built"}
`demo/build.mjs` runs `buildStyleguide()` against `test-styleguide/` and copies the plain CSS,
JavaScript and icon files next to the output. A GitHub Actions workflow publishes the result to
GitHub Pages on every push to `main`.
:::
