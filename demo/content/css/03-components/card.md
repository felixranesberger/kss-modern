Cards group one project with its status, progress and team. The Pug template
includes the shared `+icon` and `+progress` mixins.

Use the **Theme** dropdown above the preview to see the card in the *Dusk* and
*Ocean* themes. Ocean ships as its own stylesheet that loads on demand.

:::accordion{title="Anatomy" open=true}
1. **Media** with an optional status badge
2. **Body** with eyebrow, title and a short description
3. **Progress** towards the next milestone
4. **Footer** with the team and a secondary action
:::
