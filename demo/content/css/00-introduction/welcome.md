This is a demo of [kss-modern](https://github.com/felixranesberger/kss-modern).
It documents **Verdant**, a small fictional design system, straight from KSS
comments in plain CSS files.

:::alert{type="info" title="Things to try"}
Press `Cmd/Ctrl + K` to search. Switch between System, Light and Dark in the
header and watch every preview follow. The **Theme** dropdown restyles all
previews at once. Every preview has **Copy**, **Audit** and a fullpage view.
:::
